### Расположение файлов:
*  В папке "Wire-tension" — главный файл сборки **"Модуль.iam"**
*  В папке "Wire-supply" — главный файл сборки **"Система подачи и забора проволоки.iam"**

### Информация об изготовлении деталей:
* **Проект в папке "Wire-tension"** — полностью рассчитан на печать всех деталей на 3D-принтере. Рамка выполнена в виде формы для заливки бетоном/полимербетоном.
* **Проект в папке "Wire-supply"** — содержит детали двух типов:
  * 🟠 **Оранжевые детали** — печатаются на 3D-принтере.
  * 🟡 **Бежевые детали** — вырезаются на лазерном станке из фанеры толщиной 6 мм. Фанерные детали соединены алюминиевыми трубками 8 мм.

### Типы файлов в этой папке:
* `.iam` — файлы сборок 
* `.ipt` — файлы отдельных деталей
