# Wire_supply 🧵🎛️

Прошивка для **Arduino Nano**, управляющая системой автоматической подачи свежей и отвода отработанной проволоки для **электроэрозионного станка (EDM)**.

---

## 📋 Описание системы

Система состоит из двух идентичных модулей:
* **Модуль подачи** свежей проволоки
* **Модуль отвода** отработанной проволоки

Каждый модуль оснащен катушкой и подпружиненным рычагом контроля натяжения. Шаговые двигатели вращают катушки, а скорость их вращения динамически рассчитывается с помощью **PID-регулятора** (`GyverPID`) на основе угла наклона рычагов. Это позволяет непрерывно поддерживать оптимальное натяжение проволоки.

### 🛑 Логика «мёртвой» зоны и обрыва:
* **Автоостановка**: При запуске станка, а также в случае обрыва проволоки, пружины уводят рычаги в крайнее положение. Если показания датчика выходят за рабочий диапазон (становятся **меньше 50** или **больше 600**), прошивка расценивает это как «мёртвую» зону и останавливает шаговые двигатели.
* **Быстрый старт**: Чтобы запустить систему, достаточно вручную натянуть проволоку или отклонить рычаг, выведя датчик из мёртвой зоны. Двигатели запустятся автоматически.

## 🔌 Подключение компонентов

| Компонент | Пин Arduino Nano | Описание |
| :--- | :---: | :--- |
| **Шаговый двигатель 1 (Драйвер TMC2209)** | `D3` (STEP), `D2` (DIR) | Вращение катушки 1 [4] |
| **Шаговый двигатель 2 (Драйвер TMC2209)** | `D5` (STEP), `D4` (DIR) | Вращение катушки 2 [4] |
| **Датчик AS5600 №1 (в аналоговом режиме)** | `A0` (OUT) | Положение рычага 1 [4] |
| **Датчик AS5600 №2 (в аналоговом режиме)** | `A1` (OUT) | Положение рычага 2 [4] |

## 🛠️ Настройка и калибровка датчиков AS5600

В проекте используются магнитные энкодеры **AS5600**, переведённые в аналоговый режим работы.

### 1. Перевод в аналоговый режим
Чтобы датчик выдавал непрерывное аналоговое напряжение вместо I2C/PWM сигналов, на плате модуля необходимо **отпаять резистор R4**. 
После чего датчик будет работать в аналоговом режиме и на пине **"`OUT`"** будет выдавать напряжение от 0 В до 5 В, в зависимости от положения рычага.

Размещение резистора указано на изображении ниже:

![Расположение резистора R4](../../~images/resistor.png)

### 2. Зеркальное изменение направления (DIR)
Так как модули на станке расположены зеркально друг относительно друга, направления движения рычагов противоположны. Для корректной работы PID-алгоритма нужно настроить пин `DIR` на самих датчиках:
* **На первом датчике**: Замкните пин `DIR` на **GND**.
* **На втором датчике**: Замкните пин `DIR` на **VCC**.

> **Проверка**: При наклоне обоих рычагов из начального положения в рабочее, значения на аналоговых входах должны **увеличиваться**.

### 3. Калибровка положения магнитов
Перед запуском необходимо физически отъюстировать магниты на осях рычагов. В **свободном (начальном)** положении подпружиненного рычага датчик должен выдавать значения `analogRead()` в диапазоне **от 10 до 15**.

Залейте в Arduino этот простой калибровочный скетч и вращайте магнит, пока не добьетесь значений в мониторе порта (от 10 до 15):

```cpp
void setup() {
  Serial.begin(9600);
}

void loop() {
  // Считываем значения с пинов A0 и A1
  int sensor1 = analogRead(A0);
  int sensor2 = analogRead(A1);

  // Выводим данные в монитор порта
  Serial.print("Рычаг 1 (A0): ");
  Serial.print(sensor1);
  Serial.print("\t | \tРычаг 2 (A1): ");
  Serial.println(sensor2);

  delay(150); // Задержка для удобства чтения
}
```
