# Прошивка и исходный код

В этой папке находится исходный код (скетчи Arduino) для подсистем управления электроэрозионного (EDM) станка. Прошивка разделена на модули для трех отдельных микроконтроллеров.

## Обзор подсистем

*   📂 **[EDM_NEW](./EDM_NEW)** — Прошивка генератора импульсов. Отвечает за управление высокочастотными электрическими разрядами и контроль искрового промежутка.
*   📂 **[Wire_Tension](./Wire_Tension)** — Система управления натяжением проволоки. Управляет контуром обратной связи для поддержания оптимального натяжения проволоки во время работы.
*   📂 **[Wire_supply](./Wire_supply)** — Система подачи и приемки проволоки. Контролирует непрерывную подачу свежей, и отвод отработанной проволоки.
